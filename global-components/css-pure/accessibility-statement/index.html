Declaración de Accesibilidad Web

Nuestro Compromiso

Nos esforzamos para que este sitio web sea accesible para todas las personas, independientemente de sus capacidades físicas, cognitivas o técnicas. Creemos firmemente en la inclusión digital y en la creación de un internet libre de barreras.

Estándar de Cumplimiento

Este sitio ha sido diseñado y maquetado siguiendo las Pautas de Accesibilidad para el Contenido Web (WCAG 2.2) en su nivel AA. Se han utilizado etiquetas semánticas nativas y técnicas de navegación estructural para facilitar el uso con tecnologías de asistencia, como lectores de pantalla.
